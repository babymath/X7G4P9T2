📐 Infix · Postfix · Prefix notation, conversion & use

📍 Infix inf
✧ standard form
A + B  ·  (C - D) * E
⟹ operator between operands
human-friendly
Example: (3 + 4) × 5 → 35
needs parentheses & precedence
📎 Postfix post
✧ reverse Polish (RPN)
A B +  ·  C D - E *
⟹ operator after operands
no parentheses needed
Example: 3 4 + 5 × → 35
evaluated left‑to‑right using stack
🔖 Prefix pre
✧ Polish notation
+ A B  ·  * - C D E
⟹ operator before operands
no ambiguity
Example: × + 3 4 5 → 35
operator precedes operands
Same expression (infix): (A + B) * C → A B + C * (postfix) → * + A B C (prefix)

Method: Build an expression tree from infix, then do a pre‑order traversal (root → left → right). Alternatively, scan infix right‑to‑left (reverse of postfix conversion).

📌 3. Postfix ↔ Prefix (direct reversal method)
Rule: Reverse the postfix expression, swap each operator with its operands (or build a tree and do pre‑order). Let’s use the stack method for clarity.

Reverse: - / E D * C + B A
